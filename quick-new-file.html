macOS Shortcut

快速新建文件

一个用于 macOS Finder 的快捷指令脚本。配置完成后，可以在右键菜单或菜单栏快速创建 txt、md、Office 占位文件、代码文件、文件夹等常用项目。

下载脚本 查看教程

一、创建新的快捷指令

  1. 打开 Mac 上的“快捷指令 Shortcuts App”。
  2. 点击窗口顶部的“+”按钮，新建一个快捷指令。
  3. 点击顶部的快捷指令名称，把名字改成“快速新建文件”。
  4. 在右侧搜索框中搜索“Shell”，找到并添加“运行 Shell 脚本”。英文系统中叫“Run Shell Script”。
  5. 在动作里把 Shell 设置为“zsh”。
  6. 把“传入输入内容”设置为“作为参数”。英文系统中一般是“Pass Input: as arguments”。
  7. 删除脚本框里原来的内容，把下载的完整脚本代码粘贴进去。
  8. 不要勾选“以管理员身份运行”。这个快捷指令只是创建文件，不需要管理员权限；开启管理员运行后，创建出来的文件可能会出现读写权限问题。

二、添加到 Finder 右键菜单

  1. 在快捷指令编辑页面，点击右上角的“ⓘ”信息按钮。
  2. 打开“作为快速操作使用”。英文系统中叫“Use as Quick Action”。
  3. 勾选“访达 Finder”。
  4. 勾选“服务菜单”。
  5. 在顶部“接收输入”的位置，建议设置为“文件和文件夹”。这样右键文件夹或文件时都可以运行。
  6. 保存快捷指令。

三、如果右键菜单没有显示

  1. 打开“系统设置”。
  2. 进入“隐私与安全性”。
  3. 找到“扩展”。
  4. 进入“访达 Finder”。
  5. 找到“快速新建文件”，把它打开。
  6. 回到 Finder，右键一个文件夹，应该可以看到“快速操作 → 快速新建文件”或者“服务 → 快速新建文件”。

四、添加到菜单栏

  1. 打开“快捷指令 Shortcuts App”。
  2. 在左侧边栏找到“所有快捷指令”。英文是“All Shortcuts”。
  3. 找到“快速新建文件”。
  4. 在左侧边栏找到“菜单栏”。英文是“Menu Bar”。
  5. 把“快速新建文件”拖到“菜单栏 Menu Bar”分类里。
  6. 之后 Mac 顶部菜单栏会出现快捷指令图标，点击后就可以运行“快速新建文件”。

五、从控制中心添加菜单栏入口

  1. 点击 Mac 右上角的“控制中心”。
  2. 点击“编辑控制项”。英文是“Edit Controls”。
  3. 找到和快捷指令相关的选项，例如“运行快捷指令”或“显示‘菜单栏’集合”。
  4. 添加后，就可以从菜单栏或控制中心快速运行快捷指令。

六、使用方法

Finder 右键使用

  1. 打开 Finder，找到一个文件夹。
  2. 右键这个文件夹。
  3. 点击“快速操作 → 快速新建文件”。
  4. 选择文件类型，输入文件名。
  5. 选择创建后的操作，例如“只创建”“显示”“复制路径”。

菜单栏使用

  1. 点击 Mac 顶部菜单栏的快捷指令图标。
  2. 选择“快速新建文件”。
  3. 按提示选择文件类型并输入文件名。

七、推荐最终设置

快捷指令名称：快速新建文件 Shell：zsh 传入输入内容：作为参数 以管理员身份运行：关闭 作为快速操作使用：开启 访达 Finder：开启 服务菜单：开启 菜单栏 Menu Bar：可选开启 接收输入：文件和文件夹

这样设置后，它既可以在 Finder 右键菜单里使用，也可以从 Mac 顶部菜单栏快速运行。
