OBS STUDIO PLUGIN · macOS

OBS Split Recorder

一键将 OBS 录像画面与麦克风声音分别保存。

OBS 继续负责保存视频画面，插件会将选定的麦克风声音单独保存为音频文件，方便后期剪辑、降噪、调整音量或重新配音。

当前下载仅支持 macOS M 系列芯片适用于 M1、M2、M3、M4 及后续 Apple Silicon Mac。Intel Mac 与 Windows 版本正在制作中。
下载 Apple Silicon 版 查看开源项目

当前版本仍处于测试阶段，正式录制前请先进行约 1 分钟测试。

FEATURES

主要功能

跟随 OBS 原生录制流程，同时给独立麦克风音频更稳妥的保护。

跟随 OBS 录制

直接跟随原生“开始录制”、“停止录制”，并支持暂停与继续。

独立音频文件

视频与麦克风分别保存，支持 WAV、M4A 和 MP3，自动跟随 OBS 视频名命名。

音频处理预设

提供降噪、噪声门、压缩器与限制器预设，并可调整录音延迟。

冲突自动处理

自动处理麦克风静音与录像音轨冲突，停止录制后恢复原有设置。

实时状态提示

提供音量、无信号与爆音提示，支持紧凑模式和可滚动面板。

异常恢复

OBS 意外退出后，插件会尝试恢复尚未完成的 WAV 录音。

中英文界面

自动识别 OBS 界面语言，也可以手动选择中文或英文。

可靠的 MP3 转换

依次尝试内置 LAME、系统 LAME 与 FFmpeg，转换失败时保留原始 WAV。

INSTALLATION

一键安装

  1. 完全退出 OBS Studio解压下载的插件安装包。
  2. 右键点击 Install Split Recorder.command选择“打开”。如果 macOS 阻止脚本启动，请进入“系统设置 → 隐私与安全性”，在安全提示处选择允许或“仍要打开”，然后再次启动脚本。
  3. 等待终端显示安装完成脚本会自动复制插件并执行必要的临时签名。
  4. 重新启动 OBS Studio在顶部菜单进入“停靠窗口 → Split Recorder”。
脚本被 macOS 拦截时打开“系统设置 → 隐私与安全性”，向下找到对 Install Split Recorder.command 的安全提示，允许启动或点击“仍要打开”。完成后再右键脚本并选择“打开”。
默认安装位置~/Library/Application Support/obs-studio/plugins
如果系统提示脚本没有执行权限

打开“终端”，输入 chmod +x （末尾保留一个空格），将 Install Split Recorder.command 拖入终端后按回车。之后再次右键脚本并选择“打开”。

FIRST RECORDING

第一次使用

  • 开启插件总开关
  • 选择要单独录制的麦克风
  • 选择 WAV、M4A 或 MP3
  • 选择音频保存位置
  • 保持“跟随 OBS 原生录制按钮”开启
  • 建议开启“自动解决麦克风冲突”

MIC CONFLICT

麦克风冲突处理

开启“自动解决麦克风冲突”后，插件会保存麦克风原来的静音与音轨状态，录制时临时将它移出 OBS 主录像音轨，停止后再恢复原设置。桌面声音、游戏声音与其他音频来源仍由 OBS 音轨设置控制。

MP3 OUTPUT

MP3 输出

插件优先使用安装包内置的 LAME MP3 编码器，通常无需额外安装。若内置编码器无法使用，可执行 brew install lame。只有确认 MP3 转换成功后，临时 WAV 才会被删除。

UNINSTALL

卸载方法

完全退出 OBS，右键安装包内的 Uninstall-Split-Recorder.command 并选择“打开”，即可删除已安装的插件。
